#### **microsoft-lst-bench**
*Java | Apache License 2.0 | Updated Apr 2025*

LST-Bench is a comprehensive framework designed for evaluating Log-Structured Tables (LSTs) such as Delta Lake, Apache Hudi, and Apache Iceberg. This benchmarking tool allows users to run performance tests specifically designed for evaluating these modern data lake table formats, providing crucial insights into their performance characteristics and trade-offs.

**Key Features:**
- Benchmarking framework for Delta Lake, Apache Hudi, and Apache Iceberg
- Performance evaluation and comparison tools
- Comprehensive test suites for LST operations

[View on GitHub](https://github.com/KushShriv/microsoft-lst-bench)
